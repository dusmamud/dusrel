Dusrel's username generator suggests names built from two-word combinations, such as an adjective plus an animal or object. Open it at [dusrel.com/pass/username-generator/](https://dusrel.com/pass/username-generator/) and follow the steps below. Everything is generated locally in your browser.

## Steps

1. **Open the tool.** Twelve username suggestions appear straight away, using the default settings: the `Cool` style, all lowercase, with no separator.
2. **Pick a style.** Under `Style`, choose one of three themes:
   - `Cool` — punchy words like Swift, Neon, and Falcon
   - `Nature` — words like Misty, River, and Willow
   - `Tech` — words like Cyber, Pixel, and Byte
3. **Pick the case.** Under `Case`, choose `lowercase` (for example `swiftwolf`) or `Capitalized` (for example `SwiftWolf`).
4. **Pick a separator.** In the `Separator` dropdown, choose how the two words are joined: `None`, `_`, `.`, or `-`. That turns the same pair into `swiftwolf`, `swift_wolf`, `swift.wolf`, or `swift-wolf`.
5. **Add numbers if you want.** Tick `Add numbers` to append a two- or three-digit number to each suggestion, joined with the same separator you picked — for example `swift_wolf_42`.
6. **Get a fresh batch.** Click `Generate usernames` for twelve new, unique suggestions. Changing the style, case, separator, or numbers option also refreshes the list immediately.
7. **Copy the one you like.** Click any suggestion to copy it. It briefly shows `Copied!`, and you can then paste it into a sign-up form or profile.

## Tips

- **Keep generating until one fits.** There is no limit on how many batches you can generate, so run through a few sets before settling on a name.
- **Every batch is unique.** The twelve suggestions in one batch never repeat each other, so you are always choosing between twelve genuinely different names.
- **Try all three styles before deciding.** The same settings with a different style produce a completely different feel — a `Tech` name suits a coding or gaming profile, while a `Nature` name suits a personal account.
- **Match the platform's rules.** Some platforms do not allow dots, or limit how long a name can be. If a suggestion is rejected, try a different separator or turn numbers off.
- **Check availability yourself.** The tool does not check whether a name is already taken — that can only be confirmed on the platform where you want to use it. If your first choice is taken, generate another batch or add numbers to make it more distinctive.
- **Shorter is usually easier to remember.** A two-word name with no separator or a single underscore tends to be the easiest for other people to type and recall.
